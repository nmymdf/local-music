# 手機音樂（local-music）

*作者：ArchieKUO*

播放手機裡的歌，可以自己新增分類，能自動分類，記得你常聽的歌。不需要網路、不付費。

## 下載 APK

每次推到 `main`，GitHub Actions 會自動編譯，APK 放在 `apk` 分支：

- `local-music-latest.apk`：最新版
- `local-music-vX.Y.apk`：各版本

簽章固定，新版可以直接覆蓋安裝舊版，不用先解除安裝。

## 目前版本 v0.3 有的功能

- 掃描手機內的歌曲，背景播放，鎖屏和通知列控制
- 分類：中文、英文、抒情、安靜、佛曲、跑步，可新增、改名、刪除
- 自動分類：語言（看歌名歌手文字）、資料夾或關鍵字（佛曲、跑步預設有一組，可自己改）
- 常聽：播放滿一段時間算聽過一次，達到門檻（預設 10 次）自動歸進「常聽」
- 勾選多首歌，再按工具列按鈕：加入分類、移出分類、真的刪除檔案
- v0.2 新增：背景估算節拍（BPM），「跑步」（快歌）和「慢音樂」（慢歌）自動分類，界線可在管理裡改
- v0.3 新增：「整理」畫面（建議／歌手／資料夾，勾選後一次歸類）、「安靜」改看平均音量、作者與版本移到每頁右上角
- 權限：只讀取音樂，不申請網路權限
